geometor.aquinas.compile_codex¶

Compile the scientia_mathematica Multi-Track Book Codex RST tree from resources/.

Generates: - docsrc/scientia_mathematica/index.rst (:layout: book Conspectus Operis) - docsrc/scientia_mathematica/prooemium/prooemium-{en,la,summary,notes}.rst - docsrc/scientia_mathematica/pars-{1..5}/pars-{1..5}-{en,la,summary,notes}.rst - docsrc/scientia_mathematica/{concordance,bibliography,persons,glossary}.rst
